**Estado:** inventario inicial aprobado para revisión de contenido

Las instrucciones detalladas se mantienen en [EXERCISE_INSTRUCTIONS.md](EXERCISE_INSTRUCTIONS.md). Las imágenes quedan fuera de esta revisión y se incorporarán posteriormente.

Este catálogo contiene 60 ejercicios sin equipamiento para el MVP. Las cantidades y tiempos son valores iniciales para el sistema experto; no sustituyen una evaluación médica.

## Convenciones

- **Bajo impacto:** apropiado como opción inicial o alternativa.
- **Moderado:** requiere control técnico y tolerancia normal al esfuerzo.
- **Alto impacto:** incluye saltos o aterrizajes; debe ofrecer una alternativa de bajo impacto.
- Cada ejercicio requiere una imagen local de referencia, instrucciones paso a paso, advertencia breve y variantes.
- Los tiempos y repeticiones pueden ser modificados por la rutina o el sistema experto.

## Reglas de contenido y seguridad

### Intensidad base para el sistema experto

La intensidad se mantiene separada del impacto articular. Esta es la intensidad inicial; el sistema experto podrá modificarla según nivel, esfuerzo y rendimiento.

- **Baja:** EX-001 a EX-006, EX-009, EX-013, EX-015, EX-019 a EX-021, EX-029, EX-032, EX-033, EX-035, EX-037 a EX-039, EX-046, EX-053 a EX-060.
- **Moderada:** EX-007, EX-008, EX-010 a EX-012, EX-014, EX-016, EX-017, EX-022, EX-024, EX-026 a EX-028, EX-030, EX-031, EX-034, EX-036, EX-041, EX-043, EX-045, EX-048, EX-050.
- **Alta:** EX-018, EX-023, EX-025, EX-040, EX-042, EX-044, EX-047, EX-049, EX-051, EX-052.

Cada ejercicio deberá incorporar además una advertencia específica cuando exista riesgo técnico, carga elevada sobre muñecas u hombros, flexión lumbar exigente o impacto articular.

- Las imágenes deben mostrar una posición inicial y una posición final o una secuencia simple.
- No se utilizarán imágenes con equipamiento visible.
- Las instrucciones deben describir postura, movimiento y respiración en lenguaje sencillo.
- Los ejercicios de alto impacto deben mostrar explícitamente su alternativa de bajo impacto.
- Si el usuario reporta dolor, la aplicación debe recomendar detener el ejercicio y no diagnosticar la causa.
- El contenido debe revisarse antes de integrarse en rutinas y planes personalizados.
- El sistema experto no podrá seleccionar una variante avanzada si el nivel del usuario o su historial no cumplen las reglas de progresión.
